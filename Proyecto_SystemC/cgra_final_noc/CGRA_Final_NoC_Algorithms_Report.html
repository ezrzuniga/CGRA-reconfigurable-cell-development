GEMM 2×2 — systolic matrix multiply

The classic embedding: all four MAC cells form a 2×2 systolic block. A streams in from the west (one row per feed step), B from the north (one column per feed step); each MAC accumulates one output element while relaying the operand its neighbor still needs.

SumReduce8 — 8-input binary tree

Only 4 real edges for 8 inputs, so each direct-entry cell time-multiplexes its port (value 1, then value 2) and accumulates in its own register before the spatial tree-combine starts. This is the one workload where all four MAC cells compute a real sum, not just a relay.

FFT4 — 4-point radix-2 butterfly

Escalar drops out here — its scalar bridge collapses a Link to one lane, which would silently discard the imaginary part of any complex value routed through it, so x3 instead travels P10 → P11 → P01. The P00 → P01 link is reused for two different values at two different times: x1 early, then b later, once P01 no longer needs x1.

Algorithm 4 of 4

Softmax4 — base-2 exponential + reduction

The mesh has no exponential or divide, so it computes the parallel part only: 2ˣ per element via an exact bit-shift, then a 2-level reduction tree. The single division that turns the sum into a probability distribution happens once, off-array, in the testbench — the same split a real accelerator makes.
